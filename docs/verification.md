## 实际界面回放

通过 Computer Use 操作已发布的 EXE：

- 主界面正常显示，截图热键可以启动覆盖层。
- 冻结虚拟桌面并拖选自建验收画布，观察尺寸、遮罩、绿色边框和工具栏。
- 矩形工具的颜色/线宽面板可打开，实际绘制红框。
- Ctrl+Z 撤销红框，Ctrl+Y 恢复。
- Ctrl+S 打开原生文件保存对话框。点击取消后，原选区和工具栏保留，可以再次打开保存对话框。

保存路径已在对话框中输入，但实际点击保存前窗口消失，后续检测到用户输入，停止 UI 操作。没有生成 acceptance.png，因此**不把保存落盘或输出图片视觉检查记为通过**。

当前工具在 4480×1440 虚拟桌面覆盖窗口上仅展示主屏 2560×1440，输入横坐标需要按工具映射换算；这是验收工具坐标映射限制。实际不同 DPI/多屏组合仍需单独验收。

## 审查和修复

### 1.0.1 快捷键修复

旧版没有明确的录入/保存状态，F6 等功能键被忽略，在编辑当前已经注册的组合时也没有暂停全局注册。改为主窗口“修改 → 按键录入 → 保存/取消”，编辑期间注销当前热键并阻止触发截图。按键在控件的命令键处理阶段录入，避免控件自身快捷操作干扰。快捷键冲突会保留编辑状态，取消恢复原注册；保存后写入配置。

新增 F6 的自动检查在修复前实际失败，修复后通过。通过已发布的 1.0.1 界面实际验证：F6 可录入；随后按 Ctrl+A，预览从 F6 变为 Ctrl+A，编辑期间未触发截图；点击保存，配置写入数值 131137（Ctrl+A）；重新启动仍显示 Ctrl+A；在单独的 Fixture 验收画布获得焦点时按 Ctrl+A，WeShot 创建 4480×1440 截图覆盖层。对应生命周期日志时间为 2026-10-27T15:03:00Z。当前用户配置保留为 Ctrl+A。

功能键的实际全局触发、PrintScreen 的系统冲突以及冲突后重试/取消分支仍未逐项进行 UI 回放，规则检查通过不等于所有系统组合都能注册。

代码审查识别并修复：OCR 错误信息被当成识别结果、稀疏新增内容被采样去重误判、超长贴图缩放上下界异常。另补充快速马赛克拖动插点，保存对话框保留父编辑层。审查回看未报告新增 P1/P2；这不代表全部行为或 1:1 一致性已验证。
