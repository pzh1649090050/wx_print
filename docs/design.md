# 独立截图器设计

目标：依据微信 4.1.15.56 的截图界面和行为，在 Windows 10/11 上重建独立截图器。用户已授权实现并连续要求继续；采用原生 C# / WinForms，所有图标和实现重新编写，不依赖或分发微信模块。

捕获冻结虚拟桌面，覆盖窗口使用物理像素坐标；支持窗口吸附、拖选、八方向缩放、移动、放大镜和颜色值。选区边框绿色，选区外半透明黑，工具条白底圆角。标注包括矩形、椭圆、表情、箭头、自由画笔、马赛克和文字，提供颜色、粗细、撤销与重做。

导出只渲染选区和标注，不包含遮罩、边框或工具栏。支持剪贴板、PNG/JPEG/BMP 文件、桌面置顶贴图。滚动截图使用连续屏幕帧的垂直重叠匹配；匹配不可靠时明确报告，不静默误拼。OCR 调用 Windows 本地语言包，不上传图片。翻译入口先识别，再由用户主动点击打开浏览器在线翻译，并明确其文本传输。

启动界面提供截图、快捷键与托盘；默认 Ctrl+Shift+A，避开微信 Alt+A。热键冲突给出提示，可自定义。按 Esc 取消，Enter/Ctrl+C 完成，Ctrl+S 保存，Ctrl+Z/Ctrl+Y 撤销/重做，方向键微调，Shift 加速。

验收：选区裁剪像素尺寸正确，反向拖拽、负屏幕坐标、移动/缩放边界无越界；标注与导出一致；拼接已知重叠样本正确；本机启动并执行选区、标注、复制、保存、贴图与关闭。未观察或未验证的原版特性在分析文档保留，不声称已达全功能 1:1。
