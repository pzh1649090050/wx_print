# 独立截图 WeShot

根据微信 4.1.15.56 截图界面的观察与 REA 静态证据，重新实现的 Windows 截图工具。当前交付可运行的独立重建版，尚未达到严格的全功能、像素级 1:1；没有直接抽取或加载微信截图 DLL。

## 启动

双击 `dist/WeShot.exe`。面向 Windows 10 版本 2004（19041）及以上、Windows 11，x64。发布包自带 .NET 运行时，无需安装微信或另装 .NET；首次运行可能需要片刻解压运行时。

默认全局快捷键为 **Ctrl+Shift+A**，避免与微信的 Alt+A 冲突。也可在主窗口点击“开始截图”。修改方式：点击“修改”或快捷键输入框，按下新组合键，再点击“保存”（或 Enter）；Esc /“取消”保留原设置。编辑时会暂停当前截图热键，避免录入过程中触发截图。支持 Ctrl / Alt 组合键、F1–F24、PrintScreen；普通字母不能单独作为全局快捷键。系统占用或保留的组合会显示冲突提示；“重置”恢复默认键。

当前机器已按用户要求设置为 **Ctrl+A**，并验证重启保留与其他应用中触发。此设置会占用 Ctrl+A 原有的“全选”操作。关闭主窗口后驻留托盘，右键托盘可打开主窗口或退出。再次启动程序会请求已有实例开始截图。

## 截图和标注

1. 启动截图后，桌面画面冻结。拖动框选区域，或单击吸附的窗口。
2. 拖动边框八个调整点改变范围；未选标注工具时，可拖动区域移动选区。按 Tab 返回移动选区状态。
3. 工具栏提供矩形、椭圆、表情、箭头、画笔、马赛克、文字；按需选择颜色、粗细与字号。
4. 点击完成或按 Enter / Ctrl+C，将图片复制到剪贴板；在目标应用按 Ctrl+V 粘贴。保存按钮或 Ctrl+S 可保存为 PNG、JPEG、BMP。取消文件保存会保留选区，Esc 取消截图。

| 按键 | 作用 |
| --- | --- |
| Ctrl+Shift+A | 默认全局截图快捷键，可修改 |
| Enter / Ctrl+C | 完成并复制选区 |
| Ctrl+S | 保存图片 |
| Ctrl+Z | 撤销 |
| Ctrl+Y / Ctrl+Shift+Z | 重做 |
| 方向键 / Shift+方向键 | 移动选区 1 / 10 像素 |
| Tab | 返回选区移动状态 |
| Esc | 取消截图 |
| Ctrl+Enter | 提交正在输入的标注文字 |

选区前显示放大镜、坐标与颜色；此时 Ctrl+C 复制十六进制色值。导出图片只包含选区和标注，不包含遮罩、绿色边框或工具栏。

## 置顶贴图

点击“置顶在桌面”将选区变为浮动贴图。拖动移动，滚轮缩放，Ctrl+滚轮调整透明度，双击或 Ctrl+C 复制，Ctrl+S 保存。右键有更多操作，Esc 或右上角关闭按钮关闭贴图。

## 滚动截图

框选目标应用的可滚动内容，避开固定标题、工具栏与悬浮按钮，再点击“滚动截图”。不要在初始帧添加标注，以免影响匹配。

使用“向下滚动并采集”，或自行滚动后点击“采集当前画面”。每次保留足够的上一帧内容以便匹配；滚动过快、动画、重复纹理、固定元素可能导致拒绝拼接。查看预览后继续，可撤销最近三次拼接，再保存、复制或贴图。当前高度上限为 25000 像素。程序在无法确认重叠时提示失败，需要回到有重叠的位置重试。

## 提取文字与翻译

提取文字调用 Windows 本地 OCR，识别图片不上传。识别语言取决于本机已安装的 Windows OCR 语言组件，识别窗口支持切换语言与重新识别；缺少组件时给出提示。

翻译入口先进行本地 OCR，用户点击“在浏览器翻译”后，将识别结果的前 1000 字发送到 Bing 在线翻译。它与微信的翻译服务不同。转发入口将图片复制到剪贴板，随后由用户在目标应用粘贴。

## 与原版的差异及验证边界

- 选区、绿色边框、遮罩、浮动工具栏及基本标注根据观察重建；图标、字体、间距、抗锯齿、马赛克强度和细节交互未完成逐像素比对。
- 长截图使用独立的垂直重叠匹配算法，尚未完整回放实际滚动应用；没有恢复微信原版的拼接、中断恢复及 HDR 算法。
- OCR 使用 Windows 引擎；翻译、转发按上文实现。未接入微信联系人、私有服务或 AI 功能。
- HDR、受保护窗口、远程桌面、不同缩放比例的多屏组合及跨屏边界尚未完成兼容性验收。
- 已运行 24 项自动检查，并实际回放启动、框选、矩形标注、撤销/重做、取消保存后保留选区，以及 Ctrl+A 的录入、保存、重启保留和跨应用触发。文件保存落盘、贴图操作及全部标注工具的端到端界面验收仍待补全。详见 `docs/verification.md`。

配置存放于 `%LOCALAPPDATA%\WeShot\settings.json`。诊断日志位于同目录的 `diagnostics.log`，记录截图生命周期、尺寸和异常，不记录截图像素或识别文本。OCR 过程中生成本机临时 PNG，并在识别结束后尝试删除。

## 源码与构建

源码在 `app/`，检查程序在 `tests/`，分析证据在 `evidence/`，REA 报告在 `docs/analysis.md`。构建需要可编译 net7.0 Windows 项目的 .NET SDK 及 NuGet 网络访问；当前机器使用 SDK 7.0.306。现有版本使用 .NET 7，后续维护宜迁移至受支持的 LTS 运行时。

```powershell
dotnet run --project tests/WeShot.Tests.csproj -c Release
.\build.ps1
```

默认生成自包含单文件 `dist/WeShot.exe`。`build.ps1 -FrameworkDependent` 可生成依赖已安装 .NET 7 Desktop Runtime 的版本。测试 OCR 检查在没有本机识别语言时会明确跳过，因此应查看通过项数和跳过记录。

`tests/Fixture.csproj` 是无用户数据的可滚动验收画布，不属于交付程序。严格 1:1 对照工作尚未完成，剩余项目见 `docs/plan.md`。
